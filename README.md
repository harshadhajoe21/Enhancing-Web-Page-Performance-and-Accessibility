# Week 4 – Enhancing Web Page Performance and Accessibility

## Project Overview

This project focuses on improving the performance and
accessibility of a static webpage using HTML and CSS.

The main objective is to create a webpage that loads
efficiently and provides a better experience for all users.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Files

1. index.html – Webpage structure.
2. style.css – Responsive and optimized styling.
3. README.md – Project documentation.

## Features Implemented

- Semantic HTML structure.
- Accessible navigation menu.
- Skip-to-main-content link.
- Keyboard-friendly navigation.
- Visible keyboard focus indicators.
- Responsive webpage layout.
- Optimized CSS styling.
- Reduced-motion accessibility support.
- Descriptive page title and meta description.

## Performance Improvements

- Avoided unnecessary external libraries.
- Used system fonts to reduce external requests.
- Reduced unnecessary CSS repetition.
- Used simple and reusable CSS classes.
- Avoided unnecessary images and external assets.
- Used responsive CSS media queries.

For production deployment, HTML and CSS can be minified.
Images should be compressed and resized when used.

## Accessibility Improvements

- Used semantic HTML elements.
- Added proper heading hierarchy.
- Added navigation labels.
- Implemented keyboard accessibility.
- Added a skip navigation link.
- Provided visible focus indicators.
- Supported reduced-motion preferences.

## Testing Tools

The following tools can be used to test the webpage:

1. Google Lighthouse
2. WAVE Accessibility Checker
3. axe DevTools
4. WebPageTest

## Testing Process

- Check webpage loading performance.
- Verify keyboard navigation.
- Check heading structure.
- Review accessibility issues.
- Test the responsive layout.
- Check color contrast.
